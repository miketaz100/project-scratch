# HALO CAD: README

**SP1 v3 · 14-build/halo/cad · 2026-10-02**

## What is here

| File | What it is |
|---|---|
| `halo_params.scad` | **The only place numbers live.** The TAPE FIT block at the top holds Michael's ten measurements. Everything else is derived from them or is a bought-part dimension. Bought-part dimensions are tagged [KNOWN] or [VERIFY]. |
| `scad/*.scad` | One OpenSCAD file per printed part. Each one does `include <../halo_params.scad>`, and every dimension in it is an expression of the parameter names. Open a file in OpenSCAD (2021.01 or newer), press F6, then File > Export > STL. |
| `stl/*.stl` | The same parts, generated by Python. All are watertight, single bodies, in mm. |
| `stl/variant_small_hinge/` | Hub plates and feet for the small Southco E6-10-101-20. Use these only with the light float (CONFLICTS #1, #2). |
| `stl/_part_table.csv` | Bounding box, volume and PA12 mass for every part. |
| `stl/_assembly_preview.stl` | **Not for printing.** All parts plus dummy tubes, the Airpel and a head ellipsoid, at α = 0, β = 0, float retracted. Use it to look. |
| `bail_template.svg` | 1:1 bonding template. Print at 100 % on tiled letter paper and measure its 100 mm bar first. |
| `halo_parts.py` | The part definitions, written once. |
| `scadpy.py` | Writes both outputs from those definitions: OpenSCAD text (with parameter names kept) and manifold3d solids. |
| `gen_halo_stl.py` | Builds every STL and SCAD file, then runs the interference sweep. Exits 0 only if everything is watertight and every check passes. |
| `halo_design.py` | Prints the derived dimensions, carbon cut list, β-notch table, hairline and ear fences, mass ledger, CoM/lean and hinge torque check. Writes the template. |

## Re-making the parts for Michael's head

1. Take the ten measurements (halo.md §3) and type them into the TAPE FIT block of `halo_params.scad`.
2. Choose one of two routes.

**Route A (no Python):** open each `scad/*.scad` file in OpenSCAD, render, and export the STL. The SCAD files are parametric, so they pick up the new numbers.

**Route B (Python, also runs the checks):** with the scratchpad venv (trimesh + manifold3d):

```
PY=<cadenv>/bin/python
$PY gen_halo_stl.py                                   # STLs + SCAD + interference checks
$PY gen_halo_stl.py --set HINGE_SIZE=1 --out stl/variant_small_hinge
$PY halo_design.py                                    # numbers, ledger, torque, template
$PY halo_design.py --set HINGE_SIZE=1 --light-float   # the recommended variant
```

To try a number without editing the file, add `--set NAME=value`, for example `--set HL=203 --set HB=158`.

**Before ordering prints:** run route B once after you change anything. It is the only route that checks for collisions.

## Frames (where each STL sits)

| Part group | Frame |
|---|---|
| H01, H04, H05, H13, H14, H15 | **Head frame H, installed position.** O is the skull centre; X forward, Y left, Z up. They load together as the assembly. Feet are drawn at α_bail = 0 (leg straight up). |
| H07, H08, H09 (nodes) | Node frame: origin at the node centre; x along the bail toward the left ear (+β); y = rearward at α 0; z radially out from O. The strip post is on +y (rear). |
| H10 (carriage) | Origin on the strip's inner face; x along the track; y forward (float side); z radially out. **Install it with +x pointing to the RIGHT ear.** |
| H12 (spider) | Pad frame: z along the float axis (outward), z = 0 on its top face. |
| Small parts | Local frames, described in each `.scad` header. |

## Printing (JLC3DP)

**Default for every head-borne part:** MJF PA12-HP, grey, as-printed. Then:
- Bead-blast or light-sand any surface that will be bonded.
- Wipe with IPA.

**Tolerances (JLC):** ±0.3 mm up to 100 mm; minimum wall 1.0 mm; minimum hole Ø1.5 mm; clearance 0.2–0.4 mm. The CAD gives:

| Feature | Diameter |
|---|---|
| Sockets (tube 8.0) | 8.25 |
| Press pins (Ø3) | 2.9 |
| Sliding pins | 3.2 |
| M3 clearance | 3.4 |
| M3 insert | 4.0 |
| M4 insert | 5.6 |

**Check each socket with an offcut of tube before bonding.** If it is tight, run a 8.2 mm drill through by hand.

**Home FDM fallback** (PETG, 0.2 mm layers, 4 perimeters, 40 % gyroid):
- Hub plates flat on the outboard face.
- Feet on the cap face.
- Nodes on their side (y = 0 plane down) with supports in the sockets.
- Carriage on the cheek's outer face.
- Spider top-down.

PETG nodes need the proof test in halo.md §6.6, same as MJF.

## Checks the generator runs (current result: ALL OK)

**Sweeps:**
- foot vs hub plate over α_bail −24…111°;
- E6 leaves vs printed parts and vs each other (fold range 51…176°);
- bail tubes vs hub plates and feet over α;
- carriage vs nodes, posts and tubes, β −40…40° in 1° steps;
- float spider at full retract vs tubes and nodes, β −40…40°;
- spider and carriage vs harness clips on the right chords.

**Clearance numbers:**
- spider-to-tube at full retract ≥ 2.9 mm;
- ear cut;
- hub-axis to ear canal ≥ 25 mm;
- hinge fold limits.

**Not checked by CAD:** the pad (PAD WP), the float rod/spider vs the pad cover, and the harness arch. These are bench items.

## Known limits

**The SCAD files are long.** They are generated, and each cylinder between two points is written out as the full expression. Edit `halo_params.scad`, not the part files.

**Choices made in Python are baked into the SCAD.** Examples: which notches exist (k −3…7), and the hinge fastening type (studs or M4 inserts). After changing `HINGE_SIZE`, regenerate the SCAD with `gen_halo_stl.py`; OpenSCAD alone does not switch the fastening type.

**The [VERIFY] numbers to caliper on arrival, before ordering prints:**
- medium hinge HINGE_H, knuckle diameter and leaf thickness;
- Airpel body length and whether it includes the nose;
- the 7/16-20 nut AF and thickness;
- the CF spring coil bore;
- the D2F-01FL body and holes;
- the pogo connector size.
